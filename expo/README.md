# Signal Slate for Expo Go

This React Native version lives beside the native SwiftUI app in `PolymarketEdge.xcodeproj`. It uses Expo Go-compatible APIs, so it runs without a Mac, Xcode, Apple Developer membership, or a custom native build.

It reads the same public daily JSON feed as the SwiftUI version:

`https://raw.githubusercontent.com/coopermsick-67/poly-ios/main/docs/daily-picks.json`

The feed is generated by the root `scripts/build-daily-picks.js` job. Run **Actions → Build daily sports snapshot → Run workflow** once before expecting live picks; the starter JSON is empty until the first snapshot finishes. The workflow refreshes it daily after that.

## Import and analyze a trader TXT list

Open **Traders** and choose **Import trader list (.txt)**. The file should contain one 0x Ethereum wallet address per line. A label before or after the address is optional; blank lines and lines starting with `#` are ignored. Duplicate addresses are removed, invalid lines are counted, and a scan accepts up to 2,000 unique wallets.

Example:

```text
# optional name, address can appear anywhere on the line
Sharp Trader, 0x1234567890abcdef1234567890abcdef12345678
0xabcdefabcdefabcdefabcdefabcdefabcdefabcd  Another Trader
```

After importing, press **Start deep scan**. The scan runs on the phone with 8 wallet workers, retries rate-limited or temporary API failures, pages active positions up to 5,000 per wallet, samples the latest 100 closed positions, and checks the all-time SPORTS leaderboard for the top 2,000 official PnL and volume figures. Progress, partial results, and leaderboard coverage are shown in the app. The resulting custom scores, trader board, and up to three same-day consensus picks replace the default view for the current Expo Go session.

The TXT itself stays on the phone; the app sends wallet addresses to Polymarket's public APIs to retrieve their public data. Data access is bounded and retried, but public API throttling or phone network limits can make a 2,000-wallet scan take several minutes. Keep Expo Go open while it runs.

Score coverage is surfaced rather than guessed: a wallet matched in the leaderboard uses its official PnL and volume; unmatched wallets use estimates derived from the returned open positions and 100-position closed sample. The sampled win rate is not lifetime win rate, and a 5,000-position cap or failed API request is reported as partial coverage. No public endpoint guarantees complete lifetime trade history for every wallet.

## Quickest setup: Expo Snack in a browser

1. Install **Expo Go** from the App Store on your iPhone.
2. Open [`expo/App.js` on GitHub](https://github.com/coopermsick-67/poly-ios/blob/main/expo/App.js) in any browser and copy its contents.
3. On a computer or phone browser, open [snack.expo.dev](https://snack.expo.dev), create a new Snack, add `expo-document-picker` and `expo-file-system` in the Dependencies panel, then replace the starter `App.js` with the copied file. Choose iOS in the preview panel.
4. Scan Snack's QR code with the iPhone camera, then open the link in Expo Go. Keep the Snack page open while previewing.

Snack is Expo's in-browser React Native playground. Expo Go and Snack are free for this preview. Expo Go supports the latest Expo SDK, so keep Snack on SDK 57 for the dependency versions in this repository. The custom feed URL setting lasts for the current app session; the built-in URL already points to this repository.

## Run from Windows, Linux, or macOS

No Mac is required for Expo Go. With Node.js installed, clone this repository and run:

```sh
cd expo
npm install
npx expo start --tunnel
```

Install Expo Go on the iPhone and scan the terminal QR code. On a physical iPhone, sign in to the same Expo account in the Expo CLI and Expo Go. The tunnel option helps when the phone and computer are on different networks. You can also use `npm start` on a shared Wi-Fi network.

## Notes

- The Expo app is for development and preview in Expo Go. Expo Go does not publish a standalone App Store app.
- Use **Today**, **Traders**, and **How it works** at the bottom. Pull down on Today or Traders to refresh.
- Search the scored trader list and tap a wallet to inspect its open positions and recent sampled results.
- Picks are informational consensus signals, not guarantees or instructions to place a trade. No wallet is connected and the app cannot trade.
- Expo Go supports the current Expo SDK; this project uses SDK 57.0.27, React Native 0.86.3, React 19.2.3, and matching Expo document-picker and file-system packages.
